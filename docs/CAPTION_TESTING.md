# 雙向字幕整合測試

接續 PR #16，保留既有封面、圖片、十種語言、聊天室、搜尋及相機功能，依最新要求改回奶油淺色通話介面。原聲由 WebRTC 傳送，不播放 AI 翻譯配音。

## 自動檢查結果

- 30 項檢查通過：16 項字幕狀態／方向測試、10 項實際本地 HTTP／WebSocket 測試、4 項 UI 結構／配色檢查。
- `npm run check`、`git diff --check` 通過。
- 語音辨識與媒體裝置在自動測試中使用模擬物件；翻譯供應商回應也是測試資料。沒有用這些結果宣稱真實語音品質、iPhone Safari 排版或兩支手機已通過。
- 預設執行沙箱禁止開啟監聽埠時，HTTP／WebSocket 測試需要執行環境授予網路權限；不能把 EPERM 當成應用程式測試失敗或跳過後宣稱通過。

## 可以先用自己的筆電＋iPhone，或同事 Android＋iPhone

1. 使用 **LAB 測試網址**，不要把尚未驗收的版本部署到正式 Render。兩邊加入同一個私人測試房間。
2. iPhone 用 Safari，選繁體中文；另一台用 Chrome，選 English。兩邊使用耳機、允許網站麥克風與語音辨識。
3. 開始語音通話。接通後會嘗試啟動字幕；如瀏覽器要求手動操作，點「語音字幕」或「重新啟動字幕」。不需要每句手動送出。
4. 中文端說「我今天有點累，但還是很想你」：英文端應先看到中文原文，再看到英文翻譯。
5. 英文端說 “I had a long day, but I'm really happy to hear your voice.”：中文端應看到英文原文及繁體中文翻譯。
6. 交替至少 20 句、停頓 30 秒再說，確認字幕持續，沒有重複或錯序。自己的發言不可出現在對方發言區，自己的原文不另行呼叫翻譯。
7. 關閉或拒絕辨識權限，檢查原因與重啟按鈕；翻譯失敗時原文保留、原聲通話繼續。
8. 改成視訊重測，檢查字幕與掛斷按鈕；掛斷後確認麥克風／相機釋放，重撥不出現前次字幕。

筆電或 Android 配對測試有助驗證雙向流程，不能代替兩支真實 iPhone 的相容性驗收。iOS 是否能讓 Web Speech 與 WebRTC 同時使用麥克風，仍取決於 OS／裝置；程式可呈現失敗原因及重啟入口，尚未證實所有裝置都能成功。
